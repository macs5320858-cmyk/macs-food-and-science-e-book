## 1. 관리자 로그인

1. 웹사이트([https://[계정].github.io/macs-e-book/](https://[계정].github.io/macs-e-book/)) 에 접속합니다
2. 화면 **오른쪽 위 모서리**를 **5번 클릭**합니다
3. 로그인 창이 나타나면 관리자 이메일과 비밀번호를 입력합니다
4. **로그인** 버튼을 클릭합니다

> 관리자 계정은 Supabase 대시보드 → Authentication → Users에서 생성합니다.  
> 로그인 상태는 브라우저 탭을 닫으면 해제됩니다.

## 2. 책 관리

로그인 후 **책 관리** 탭에서 책을 추가·수정·삭제할 수 있습니다.

### 책 추가하기

1. 관리자 패널에서 **새 책 추가** 폼을 확인합니다
2. 각 항목을 입력합니다:

| 항목 | 설명 |
|---|---|
| ID | 영문 소문자 + 하이픈만 사용 (예: `solar-system`) |
| 제목 | 웹사이트에 표시될 이름 (예: `태양계`) |
| 저자 | 기본값: Macs Learning Lab |
| 카테고리 | 드롭다운에서 선택 (없음도 가능) |
| 태그 | 쉼표로 구분 (예: `과학, 우주`) |
| PDF 파일 | **새 책 추가 시 필수** |
| 배경음악 | 선택 사항 (.mp3 파일) |

3. **저장** 버튼을 클릭합니다
4. PDF가 Supabase에 업로드되고 책 목록에 즉시 반영됩니다

### 책 수정하기

1. 책 목록에서 **수정** 버튼을 클릭합니다
2. 수정할 항목을 변경합니다
3. PDF/음악 파일은 새로 선택하지 않으면 기존 파일이 유지됩니다
4. **저장** 버튼을 클릭합니다

### 책 삭제하기

1. 책 목록에서 **삭제** 버튼을 클릭합니다
2. 확인 창에서 **삭제** 버튼을 클릭합니다
3. PDF와 음악 파일도 함께 삭제됩니다

## 3. 카테고리 관리

로그인 후 **카테고리 관리** 탭에서 카테고리를 관리할 수 있습니다.

### 카테고리 추가하기

1. **새 카테고리 추가** 폼을 확인합니다
2. 각 항목을 입력합니다:

| 항목 | 설명 |
|---|---|
| 카테고리 ID | 영문 소문자 + 하이픈 (예: `earth-science`) |
| 카테고리 이름 | 표시될 이름 (예: `지구과학`) |
| 상위 카테고리 | 드롭다운에서 선택 (최상위 카테고리면 선택 안 함) |

3. **저장** 버튼을 클릭합니다

> 카테고리는 무한히 중첩할 수 있습니다.  
> 예: `과학` > `지구과학` > `화산` 처럼 여러 단계 생성 가능

### 카테고리 수정하기

1. 카테고리 목록에서 **수정** 버튼을 클릭합니다
2. 이름이나 상위 카테고리를 변경합니다
3. **저장** 버튼을 클릭합니다

### 카테고리 삭제하기

1. 카테고리 목록에서 **삭제** 버튼을 클릭합니다
2. 확인 창에 삭제 시 영향이 표시됩니다:
   - **하위 카테고리가 있으면** → 하위 카테고리도 모두 삭제됩니다
   - **속한 책이 있으면** → 해당 책들의 카테고리 연결이 해제됩니다 (책 자체는 삭제되지 않음)
3. **삭제** 버튼을 클릭합니다

## 4. 웹사이트에서 책 읽기

1. 웹사이트에 접속합니다
2. 카테고리(📁 폴더 아이콘)를 클릭하면 해당 카테고리 안으로 들어갑니다
3. 책(📖 아이콘)을 클릭하면 PDF 리더가 열립니다
4. 상단 경로(예: `전체 › 과학`)를 클릭하면 이전 화면으로 돌아갑니다
5. 오른쪽 위 모서리를 **5번 클릭**하면 관리자 모드에 진입합니다

> 배경음악이 있는 책은 리더 오른쪽 아래 🎵 버튼을 눌러 재생할 수 있습니다.  
> 브라우저 정책상 자동 재생은 되지 않습니다.

## 5. 자주 묻는 질문

**Q. 책 목록에 새 책이 바로 안 보여요**  
A. 페이지를 새로고침(Mac: `Cmd+Shift+R`, Windows: `Ctrl+Shift+R`)해 보세요.

**Q. PDF 파일명에 한글을 써도 되나요?**  
A. ID는 영문 소문자와 하이픈만 사용해야 합니다. 한글 파일명은 URL 문제를 일으킬 수 있습니다.

**Q. 카테고리 삭제하면 책도 삭제되나요?**  
A. 아니요. 카테고리를 삭제하면 해당 카테고리에 속한 책은 **카테고리 없음** 상태가 됩니다. 책 자체는 삭제되지 않습니다. 단, 하위 카테고리는 함께 삭제됩니다.

**Q. 로그인이 안 돼요**  
A. Supabase 대시보드 → Authentication → Users에서 관리자 계정이 생성되어 있는지 확인하세요. 비밀번호를 잊은 경우 같은 화면에서 재설정할 수 있습니다.

**Q. 오른쪽 위 5번 클릭이 잘 안 돼요**  
A. 화면 맨 오른쪽 위 구석을 1.5초 이내에 5번 클릭하세요. 천천히 클릭하면 인식되지 않습니다.
